### BR-08 — L'admin peut rétablir un statut impossible et revenir en arrière sur une commande livrée
- Contexte : la page d'administration permet de modifier le statut d'une commande et n'empêche pas les transitions invalides.
- Préconditions : compte administrateur connecté ; une commande déjà en statut "delivered" ou "cancelled".
- Étapes :
  1. Ouvrir le tableau de bord d'administration.
  2. Envoyer une requête de mise à jour de statut vers `POST /admin/orders/<id>/status` avec `status=confirmed` ou `status=cancelled` depuis une commande livrée.
  3. Vérifier le changement.
- Résultat attendu : les transitions en arrière doivent être interdites selon la logique métier.
- Résultat obtenu : le code accepte n'importe quel statut dans la liste autorisée sans vérifier la cohérence avec l'état précédent.
- Preuve : dans `app/routes/admin.py`, `allowed = {"confirmed", "preparing", "out_for_delivery", "delivered", "cancelled"}` et le commentaire indique explicitement : "impossible backward transitions are accepted, e.g. delivered -> confirmed or delivered -> cancelled".
- Sévérité : Majeure
- Priorité : Moyenne
