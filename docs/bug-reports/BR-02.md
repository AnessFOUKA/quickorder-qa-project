### BR-02 — Paiement PayPal dupliquant la commande
- Contexte : un client paie en PayPal, mais le système génère deux commandes identiques au lieu d'une seule.
- Préconditions : client connecté, panier non vide, adresse valide, mode de paiement "paypal" sélectionné.
- Étapes :
  1. Ajouter un produit au panier.
  2. Aller au checkout.
  3. Sélectionner le mode de paiement "PayPal" et confirmer.
- Résultat attendu : une seule commande créée, un seul paiement enregistré.
- Résultat obtenu : le backend appelle `build_order()` deux fois si `payment == "paypal"`, puis ajoute les mêmes lignes de commande à deux orders distinctes.
- Preuve : dans `app/routes/orders.py`, sous la branche `if payment == "paypal":`, le code crée un `duplicate` puis ajoute les articles à la seconde commande ; les deux commandes partagent le même total et le même panier.
- Sévérité : Critique
- Priorité : Haute
