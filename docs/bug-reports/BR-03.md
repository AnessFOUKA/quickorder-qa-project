### BR-03 — Le montant minimum de commande n'est jamais vérifié au checkout
- Contexte : le restaurant "Couscous Atlas" affiche un seuil minimum de commande de 25 € et l'utilisateur suppose que le système le bloque.
- Préconditions : client connecté, panier avec un montant inférieur à 25 €.
- Étapes :
  1. Choisir un produit d'un restaurant avec un minimum d'achat.
  2. Ajouter au panier un montant inférieur au minimum.
  3. Passer au checkout et confirmer la commande.
- Résultat attendu : le système refuse la commande avec un message explicite de montant minimum non atteint.
- Résultat obtenu : la commande est acceptée, car le code vérifie `restaurant.minimum_order` seulement dans la base de données mais ne l'applique jamais dans le flux de checkout.
- Preuve : dans `app/routes/orders.py`, le commentaire indique explicitement : "minimum_order is displayed but never enforced" ; le code ne compare pas `subtotal` à `restaurant.minimum_order` avant la création de la commande.
- Sévérité : Majeure
- Priorité : Haute
